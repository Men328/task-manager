# Kết bạn: kế hoạch triển khai

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Người dùng tìm nhau bằng email, gửi/chấp nhận/từ chối/rút lời mời, xem danh sách bạn bè và hủy kết bạn.

**Architecture:** Service mới `service/social` (gRPC `:9091`, HTTP `:8091`) sở hữu bảng `social.friendships`. Gateway HTTP là route viết tay, lấy người gọi từ bearer token, rồi gọi gRPC nội bộ. Social tra profile qua 2 RPC nội bộ mới của `identity` và gửi thông báo qua `notification`.

**Tech Stack:** Go 1.25, gRPC + grpc-gateway `runtime.ServeMux`, fx, pgx, golang-jwt; React, Mantine, Redux Toolkit, vitest.

**Spec:** `docs/superpowers/specs/2026-11-04-friends-design.md`

## Global Constraints

- Mọi HTTP route của social bắt buộc bearer token; `profile_id` của người gọi chỉ lấy từ `sub`, không nhận từ client.
- Không khai báo `google.api.http` cho RPC nào của social và 2 RPC mới của identity.
- Proto chỉ thêm, không đổi số field. Sửa xong chạy `make gen`, commit `common/gen`.
- Mã lỗi: sửa `common/errorcode/error_codes.json` + `errorcode.go`, chạy `make error-codes`.
- `internal/service` chỉ import `model`; `cmd` dùng fx; `make quality-all` phải pass.
- Mọi hàm repository có ở cả Postgres và in-memory.
- Chuỗi giao diện có đủ `vi.json` và `en.json`. Comment trong code viết tiếng Việt.
- Commit message kết thúc bằng `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. Bấm đúp "Chấp nhận", hoặc chấp nhận lời mời vừa bị rút: lần sau trả `SOCIAL_FRIEND_REQUEST_NOT_FOUND`, không lỗi 500. Test ở Task 3.
2. Id trong URL không phải UUID: trả 404 theo mã NotFound, không lỗi 500. Test ở Task 4.
3. `identity` không gọi được: trả `COMMON_UNAVAILABLE`, không báo nhầm là "không tìm thấy". Test ở Task 3.
4. Người trong danh sách hoặc lời mời đã bị xóa mềm: dòng đó bị ẩn, không lỗi, không hiện profile rỗng. Mời profile đã xóa trả `SOCIAL_PROFILE_NOT_FOUND`. Test ở Task 3.
5. Email có khoảng trắng hoặc viết hoa vẫn tìm thấy; `notification` lỗi thì thao tác vẫn thành công. Test ở Task 3.

```go
type FriendshipRepository interface {
    Create(ctx context.Context, requesterID, addresseeID string) (model.Friendship, error) // trùng cặp: ErrDuplicate
    Get(ctx context.Context, id string) (model.Friendship, error)
    GetByPair(ctx context.Context, a, b string) (model.Friendship, error)

    AcceptRequest(ctx context.Context, profileID, requestID string) error
    DeclineRequest(ctx context.Context, profileID, requestID string) error
    CancelRequest(ctx context.Context, profileID, requestID string) error
}
```
